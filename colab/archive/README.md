## Archive policy

- No notebook content or checkpoint is deleted as part of this cleanup.
- Historical notebook versions may rely on old data, license terms, tokenizer versions, GPU assumptions, paths or checkpoint layouts.
- Do not resume training from an archived notebook without checking its dataset revision, license, output directory, checkpoint format and current validation coverage.
